## Riot Games

Teamfight Tactics, Riot Client, their SDKs, names and artwork are associated
with Riot Games. This independent launcher prepares private runtime copies from
the user's installed Riot Client and retrieves game files from Riot's services.

The compatibility configuration describes Riot product identifiers, service URLs
and launch arguments. Its inclusion grants no rights to Riot Games software,
services, trademarks or artwork. Riot runtime binaries, game assets and artwork
are obtained separately from the user's installation or Riot's services.

The full SDK system configuration is generated locally from the installed
client's configuration. It remains in the user's private application data.

See [Riot Games legal information](https://www.riotgames.com/en/legal).

## Earlier Python-based releases

Launcher releases before version 1.1.0 include CPython from Python Build Standalone,
maintained by Astral. This distribution includes Python and its runtime
dependencies, with their existing license notices inside the bundled
`Contents/Resources/python` directory.

Those releases pin the distribution URL and verify its SHA-256 checksum.
See [Python Build Standalone documentation](https://docs.astral.sh/python-build-standalone/).
